# Visualisation Tutorials

* [A\_estnltk\_table\_display.ipynb](A_estnltk_table_display.ipynb) introduces table representations of EstNLTK's components and corresponding options. 

* [B\_span\_visualisation](B_span_visualisation.ipynb) demonstrates how to use `Layer.display()` for span visualization, how to customize the visualization (e.g. change background color or font type of annotations), and how to use pre-defined visualization modules for highlighting ambigious and/or overlapping annotations, words' part-of-speech tags and morphological cases, compound words and types of compound tokens. 

* [X\_attribute\_visualisation](X_attribute_visualisation.ipynb) demonstrates how to use an interacive widget class `DisplayAttributes` class for selecting concrete attribute values in Jupyter Notebook.
